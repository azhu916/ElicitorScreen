# ElicitorScreen

This repository contains scripts for candidate plant immune elicitor screening based on Harpin-derived short-sequence BLAST expansion and ProteinBERT embedding similarity analysis.

## Workflow

1. Length filtering of candidate protein sequences
2. ProteinBERT embedding extraction
3. Cosine similarity calculation
4. Candidate ranking and result export

## Environment

- Python 3.8.20
- TensorFlow 2.4.0
- ProteinBERT
- Biopython
- scikit-learn
- NumPy

## Notes

Large raw data files and pretrained model weights are not included in this repository.
